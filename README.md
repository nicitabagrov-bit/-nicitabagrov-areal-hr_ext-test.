# Areal HR Test 2025

Веб-приложение для учета сотрудников в нескольких организациях.

## 📊 Схема базы данных

Схема БД спроектирована в Draw.io и включает в себя таблицы: Организации, Отделы, Должности, Сотрудники, Файлы, Кадровые операции, История изменений, Пользователи. Везде предусмотрено мягкое удаление (`deleted_at`).

## 📁 Структура проекта
* __/api__ — исходный код бэкенда (NestJS), включая папку `/migrations`.
* __/app__ — исходный код фронтенда (Vue.js / Quasar).
* __/containers__ — файлы `Dockerfile` для сборки образов.
* __/docs__ — документация, схема БД (`.drawio`) и превью (`.png`).
* __/.env.example__ — шаблон переменных окружения.
* __/docker-compose.yml__ — конфигурация для запуска.
